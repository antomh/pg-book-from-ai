# assets/ — изображения и диаграммы учебника

Требования к файлам:

- Формат — SVG (текстовый, редактируемый, масштабируемый). Растровые PNG —
  только для скриншотов, которых нельзя заменить SVG.
- Имя файла: `nn-mm-<описание>.svg`, где `nn-mm` — номер главы
  (например, `06-04-mvcc-visibility.svg` — схема видимости версий строк).
- Внутри SVG: атрибуты `role="img"` и `<title>`; текст — кириллица допустима,
  шрифты — generic (`sans-serif`), без внешних зависимостей.
- Каждая диаграмма должна быть самодостаточной: подписи осей/узлов, легенда.
- Запрещено вставлять в SVG скрипты и внешние ссылки.
- Происхождение: диаграммы авторские (схемы устройства, сценарии конкурентного
  доступа); копирование иллюстраций из документации PostgreSQL не допускается
  без отдельного решения о лицензии (правила — `00_rules.md`).
